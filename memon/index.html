Memon

メーラーライクな３ペイン型リッチテキスト対応のメモ管理アプリ

macOS iOS Android Windows

01メモ管理

  • グループ／メモの階層ツリー管理
  • 重要度設定（★★★ / ★★ / ★ / なし）による色分け表示
  • タグ付けと一覧表示
  • グループとメモのアイコン変更 （標準18カテゴリ・12色、カスタム設定）
  • メモのソート （更新日時・作成日時・タイトル・重要度・タグ）
  • メモの別グループへの移動 （デスクトップ：ドラッグ＆ドロップ、モバイル：長押しで選択モードに入りチェックボックスで複数選択→移動）

02リッチテキスト編集

  • 太字・イタリック・下線・取り消し線
  • 文字色・背景色
  • 見出し（H1〜H3）
  • 箇条書き・番号付きリスト
  • メモ個別の背景色設定

03検索

  • 全メモを対象とした検索
  • エディタ内のテキスト検索
  • 選択テキストを Google 検索

04クラウド連携

  • iCloud Drive への保存・読み込み （macOS / iOS）
  • Google Drive への保存・読み込み （macOS / iOS / Android / Windows）
  • OneDrive への保存・読み込み （macOS / iOS / Android / Windows）

05インポート／エクスポート

  • Windows 版 旧Memon の XML メモファイルをインポート
  • 指定フォルダのテキストファイルを一括インポート
  • 選択メモをテキスト / PDF / リッチテキスト（RTF）ファイルとしてエクスポート
  • グループをフォルダ階層でテキスト / PDF / リッチテキスト（RTF）エクスポート

06その他

  • AES 暗号化によるパスワード保護
  • 印刷 （エディタツールバーから起動。プリンタ選択・余白・ヘッダー/フッター・プレビュー）
  • 付箋表示 （デスクトップにメモをウィンドウとして表示）
  • ホーム画面ウィジェット （iOS のみ）
  • フォント・背景色のカスタマイズ
  • アプリの更新確認
